# decimalx 语义标准

> **派生摘要**：本文件不是行为合同权威。`decimalx` 行为合同的唯一权威为元仓 `specs/repos/type/decimalx` 的 `SPEC.md` 与 `specs/01..10`（Owner 裁定 2026-11-05）。本文件只概述实现侧职责、范围与约束。

## 职责

`decimalx` 是精确十进制数值与金额值对象的唯一实现，不包含业务规则。

## 范围

- `Decimal` 使用整数尾数和十进制 scale 表示数值，最大 scale 为 18。
- `Price`、`Qty`、`Ratio`、`Currency` 和 `Money` 提供明确的类型边界。
- 舍入策略显式传入；除法和缩放等有损操作必须选择舍入策略。
- serde 反序列化必须经过值约束校验；wire 格式由 `WIRE_SCHEMA_VERSION` 标识。

## 约束

- 金额和数量不得以 `f32` 或 `f64` 表示或参与运算。
- 资金路径使用 `checked_*` API；默认关闭 `panicking-ops`。
- 不提供汇率换算、定价、手续费或会计政策。
- 破坏 wire shape 时必须更新 `WIRE_SCHEMA_VERSION` 与 [`WIRE.md`](WIRE.md)。
